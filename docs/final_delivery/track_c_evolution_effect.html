本局如何进入策略闭环

1
对局输入
从本局事件、发言、投票、夜间技能和复盘摘要中提取候选经验。
2
知识抽取
把“预言家查杀警长位”“守卫保护公开核心位”“票型断层归票”抽象成可复用策略。
3
生命周期治理
候选知识先进入 candidate；质量、聚类、使用反馈达标后晋级 active；未达门禁或过期内容归档。
4
检索回流
下一局 Agent 按角色、阶段、阵营和人格检索 active 策略，不读取候选池。

可抽象出的三条策略

预言家

高影响力身份位需要优先查验，查到狼人后把查验结果、票型和归票目标绑定输出。


守卫

当公开核心位被狼队集中攻击时，守护目标应优先覆盖仍能继续产出信息的玩家。


好人阵营

投票从个人怀疑升级为“查验 + 票型 + 技能佐证”的共识链，能显著缩短收束时间。

candidate

触发条件：警长位、带队位或强发言位身份不明，且其票型会影响白天归票。

策略动作：优先查验高影响力身份位；若查到狼人，次日同时公开查验结果、票型依据和归票目标。

治理边界

Track C 的目标是让策略知识可积累、可筛选、可回流，而不是把所有复盘文本都塞进下一局。两层触发机制分别处理“本局新增知识”和“全库周期治理”，从源头避免候选池过量堆积。

生产检索原则

只加载 active 策略；candidate 负责承接新经验；deprecated 负责保留审计记录并隔离未达门禁量内容。
