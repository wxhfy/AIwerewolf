# 角色认知记忆系统

## 目标

角色需要像有限认知能力的人类玩家一样记忆和判断：注意力有限、会形成主观信念、会受社会压力影响、会忘记细节，也可能坚持错误判断。同时，所有事实边界仍由后端状态机强制保证。

## 信息分层

系统禁止把主持人全局状态称为角色的“全局记忆”。角色只能拥有：

1. 公共事实：公开发言、投票、死亡和公开系统消息。
2. 角色私有事实：身份、狼队信息、查验结果等依法可见内容。
3. 主观认知：信念、关系、情绪、目标和角色自己的行动记录。

## 记忆结构

| 记忆块 | 作用 |
|---|---|
| 工作记忆 | 当前最值得关注的少量信息块 |
| 情景记忆 | 角色亲历的事件及其时间、来源、显著性和情绪色彩 |
| 信念状态 | 对每名玩家的狼人概率、置信度和正反证据 |
| 社会关系 | 信任、亲近、威胁、影响力和感知态度 |
| 情绪状态 | 愉悦度、唤醒度、支配感、恐惧、愤怒、自信和社会压力 |
| 目标状态 | 角色目标、当前决策目标和未来意图 |
| 自身行动 | 上一次行动、目标和理由 |
| 发言声明 | 跳身份、查验声明、站边、怀疑、投票承诺和撤回 |
| 证据图 | 发言者到目标玩家的带方向、权重和置信度的证据边 |

## 动态机制

```text
基础配置
+ memory_bias
+ logic_depth
+ suspicion_threshold
+ pressure_style
+ self_protection
+ courage
+ 当前情绪
+ 当前决策类型
= 本次注意窗口、检索数量、检索权重、衰减速度和事件反应强度
```

配置文件只定义机制边界和基础显著性，不固定所有角色的最终比例。运行时会归一化检索权重，保证不同人格产生不同记忆偏好。

## 更新流程

```text
接收角色安全事件
  -> 编码情景记忆
  -> 提取发言声明、承诺和矛盾
  -> 更新确定性私人事实
  -> 使用有界对数几率更新主观信念
  -> 评估社会刺激、关系和情绪变化
  -> 刷新角色目标
  -> 生成工作记忆
  -> 按当前人格和情绪检索相关事件
  -> 组装有限上下文
```

发言理解和信念更新由确定性代码完成，不增加额外模型调用。普通决策调用一步主模型，高影响决策最多增加一步受预算约束的反思。

## 上下文控制

数据库保存完整角色记忆状态，但 Prompt 只放入动态窗口。默认基数为近期事件 10 条、检索情景记忆 5 条、工作记忆 5 块，最终数量根据人格和情绪在配置边界内变化。因此长对局不会反复发送全部历史，旧事件仍可被检索和审计。

## 持久化

`actor_memories` 每个 `(game_id, player_id)` 只有一条当前状态，保存记忆模型版本、已经归纳到的最后事件序号和结构化 JSON 记忆。一次决策先在内存中吸收事件，Harness 完成、失败或降级后统一提交一次，避免决策前后重复写整份 JSON。Worker 重启后可从最后序号确定性重放尚未归纳的可见事件。

## 信息隔离

- Reducer 的输入只能是 `DecisionRequest.information_state`。
- 看不到的私人事件无法进入角色记忆。
- 狼队已知身份和预言家查验属于确定性私人信念。
- 普通玩家对身份的判断保持主观概率，不得提升为主持人真相。
- 记忆检索不提供任意数据库查询接口。

## 跨局知识边界

单局认知记忆只描述当前角色在本局看见和推断出的内容。Track C 策略通过独立的 `knowledge_context` 按来源和版本注入，不能混入 `private_memory`，也不能携带当前对局的赛后真相。后续演进重点是增加有限一层的他人心智模型，并使用 Track B 结果离线校准动态参数。
