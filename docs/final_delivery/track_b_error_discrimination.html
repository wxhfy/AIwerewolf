错误样例如何构成

每个错误都由“可见局面 + 注入动作 + 角色目标冲突”组成，因此不是单纯写低分，而是让评分器从证据链中识别矛盾。

样例构成局面注入动作评分识别点
预言家隐藏查杀夜间私有信息中，预言家已查验 P1 为狼人；白天进入公开讨论和投票阶段。预言家没有公开 P1 查杀信息，并把票投向非 P1 目标。私有查验未转化为公开证据；已知狼人未被投出；行动与预言家角色目标冲突。
狼人视角泄露白天公开桌面上，预言家已经点出 P1 查杀，狼人需要维持好人视角叙事。狼人发言出现狼队视角，并无公开证据地硬保被查杀队友。狼队视角泄露；队友保护过度；发言缺少公开证据支撑。
低价值狼刀预言家已经公开身份并持续产出查验信息，是狼人夜间的高价值目标。狼人夜间没有处理明牌预言家，而是选择低价值村民目标。刀口目标价值低；没有压制持续产出信息的关键位；行动与狼人阵营收益冲突。
女巫救下刀口女巫在夜间得到被刀目标信息，解药仍可用。女巫使用解药救下当夜刀口。技能目标与夜间信息一致；保留白天可参与发言和投票的席位；阵营收益明确。
