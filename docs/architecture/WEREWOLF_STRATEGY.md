# 狼人杀 Agent 策略层设计

## 1. 目标

策略层位于角色主观记忆和通用 Agent Harness 之间。它不读取主持人全局状态，不直接替模型决定动作，而是把角色已经看见的信息整理成稳定、可解释、可测试的策略态势。

```text
角色可见事件
  -> SpeechInterpreter：提取身份声明、查验、站边、投票承诺、撤回和矛盾
  -> CognitiveMemoryReducer：更新主观信念、关系、情绪和证据图
  -> StrategySnapshot：生成嫌疑榜、保护价值、狼刀价值和身份对跳
  -> LLMActionPlanner：结合角色目标、合法动作和策略态势完成决策
  -> 服务端校验并推进状态机
```

这一分层解决两个问题：

1. 模型不需要在每次调用时重新统计整段历史，降低遗漏、顺序混乱和上下文浪费。
2. 策略判断能够用确定性测试检查，模型仍负责语言表达、权衡和非确定性博弈。

## 2. 信息边界

策略层的唯一输入是当前角色的 `DecisionRequest.InformationState` 和对应的私有记忆：

- 公开发言、投票、死亡和公开阶段事件；
- 当前角色合法可见的私有事件，例如自己的查验结果和狼人队友；
- 当前角色自身的历史行为与记忆；
- 不包含其他神职身份、狼人完整夜间交流或主持人真相状态。

每份策略快照带有 `provenance=derived_only_from_actor_visible_memory`，表示它只是角色视角的派生信息，不是游戏事实。

## 3. 发言理解

当前规则型解释器提取以下结构：

| 类型 | 含义 | 示例 |
|---|---|---|
| `role_claim` | 自称身份 | “我是预言家”、`As P2, the Seer` |
| `check_claim` | 声称查验结果 | “3 号查杀”、“P3 is not a wolf” |
| `stance` | 怀疑或认可 | “我怀疑 4 号”、“P3 is a fake seer” |
| `vote_commitment` | 投票承诺 | “这轮我投 5 号” |
| `retraction` | 撤回旧观点 | “收回之前对 5 号的判断” |
| `contradiction` | 前后冲突 | 改跳身份、站边反转、实际投票违背承诺 |

撤回和矛盾分开处理：主动撤回会降低旧声明的有效性，但不会自动等价为狼人；无解释的冲突会降低发言者可信度并提高其嫌疑。

规则解析器选择保守识别，避免把普通提及误判成身份声明。后续可在低置信度样本上增加轻量语义模型，但输出仍必须进入同一声明 Schema。

## 4. 三套动态评分

同一个玩家在不同决策中的价值不同，因此不能用一张“狼人概率表”处理所有动作。

### 4.1 嫌疑分

用于投票、查验、猎人开枪和白狼王自爆候选比较。输入包括：

- 主观狼人概率和置信度；
- 发言矛盾次数；
- 是否卷入唯一身份对跳；
- 当前角色对该玩家的信任。

矛盾和对跳只是增量证据，不会覆盖确定性私有信息。

### 4.2 保护价值

用于守卫目标和警徽移交。输入包括：

- 主观好人概率；
- 判断置信度；
- 公开影响力；
- 当前信任程度。

保护价值与嫌疑分独立，避免守卫机械保护“最低狼人概率但没有局势价值”的玩家。

### 4.3 狼刀价值

用于狼人夜间目标。输入包括：

- 非狼可信度；
- 公开影响力；
- 对狼队的威胁；
- 角色对判断的置信度。

已由角色私有信息确认的狼人队友会被排除，避免模型或兜底逻辑误刀队友。

这些评分的系数目前是解释性启发式，不是固定的最终策略。后续应通过 Track B 指标和 Track C 配对实验调整，而不是直接按单局胜负修改。

## 5. Planner 上下文

Planner 当前接收独立的 `strategy_state`：

```json
{
  "actor_role": "Villager",
  "decision_kind": "werewolf.vote",
  "suspect_ranking": [],
  "protection_ranking": [],
  "wolf_attack_ranking": [],
  "role_claims": [],
  "contested_roles": [],
  "decision_guidance": [],
  "provenance": "derived_only_from_actor_visible_memory"
}
```

模型仍必须从服务端提供的 `option_id` 中选择，不能用策略快照创建非法动作。模型调用失败时，确定性兜底也消费同一套动态评分，避免退化为固定选择第一个目标。

## 6. 2026-09-21 实测

使用智谱官方免费模型 `glm-4-flash-250414` 完成 7 人真实整局：

| 指标 | 结果 |
|---|---:|
| 最终阶段 | `GAME_END` |
| 数据库状态 | `finished` |
| 模型决策 | 28 |
| 非法决策 | 0 |
| 兜底决策 | 0 |
| Harness 事件 | 234 |
| 角色记忆 | 7 |
| 结构化声明 | 42 |
| 声明类型 | 查验、站边、投票承诺 |

该局没有产生公开身份对跳或真实的前后改口，所以对跳和矛盾计数为 0。这只能证明链路能够收集和消费策略信息，不能证明对跳识别率已经充分。相应模式已通过人工构造的中英文回归测试覆盖。

## 7. 下一阶段

1. 从真实对局抽取发言，建立身份声明、站边、承诺、撤回和矛盾的人工标注集。
2. 增加票型阵营分析，例如互保、集火、倒钩和关键轮次换票。
3. 为预言家、女巫、守卫和狼人增加独立的时机价值特征，而不是只比较目标玩家。
4. Track B 增加证据引用率、跨轮一致性、信息泄漏和角色任务评分。
5. Track C 使用同 Seed、同座位和同角色分配的配对实验调整策略参数。
